# Beta bug-report checklist

For testers reporting a MemePet problem. No monitored support contact is
confirmed yet (`SUPPORT_URL` is `null`), so this lists what to send, not where.

## Include

- [ ] **Page URL**, for example `https://memepet.vercel.app/pet` or a public pet page.
- [ ] **Browser** and version, and the **wallet app** (OKX Wallet, MetaMask or other).
- [ ] **Network** your wallet showed (expected: X Layer testnet, chain 1952).
- [ ] **Steps**: what you did, what you expected, and what you saw, in order.
      Include the exact on-screen message if there was one.
- [ ] **Time** it happened, in UTC if you can.
- [ ] Optional: the **public transaction hash** and your **public wallet address**.
- [ ] Optional: a screenshot that shows only the MemePet page.

## Never include

- Seed phrase / recovery phrase, private key or keystore file.
- Wallet, email or any other account password, or a one-time code.
- Screenshots of your wallet's secret or settings screens.

MemePet never needs these to look into a problem. A public address and a
transaction hash are enough. Anyone asking for secrets is not MemePet.
