## Defect found and fixed — artwork focus ring overlap

| | |
|---|---|
| Where | `src/components/landing/landing.module.css` (F4 allowlist) |
| Reproduce | Hosted `/`, focus "Say hello to Mochi" with the keyboard |
| Cause | The artwork button fills its frame exactly (its top is the header's bottom; its bottom is the stage heading's top), and the global ring sits **5 px outside** it |
| Before (hosted) | Ring overlaps the switch and the stage heading by **4.3 px** at 1440, **6.7 px** at 390 and 320 |
| Fix | `.artButton:focus-visible { outline-offset: -4px; }` — ring drawn just inside the button |
